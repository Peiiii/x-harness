01 / TASKS

任务有名字。结果有依据。

01

读取一个任务

书签、搜索、博主、帖子与反馈。只返回相关内容，目标正文保持完整。

readBookmarks · readCreator · readPost
02

完成一次行动

发布、回复、关注。用户授权与审稿证据通过后，记录意图、提交、核验。

publishPost · replyToPost · followBatch
03

接续真实状态

提交结果未知时先查证。保留原始台账，已完成的动作不重复执行。

verifySubmission · inspectRound

02 / OUTPUT

省去噪音，
留下判断依据。

导航、重复页面信息和内部字段不占回执。需要决策时拿到完整目标证据；再次读取时只看变化。

短回执

状态 · 目标 ID · 本地证据引用 · 必要告警

{ status, ids, evidenceRef, missing }
完整目标证据

完整正文、作者、时间、媒体与来源，缺失字段明确标记。

{ status, sources, evidenceRef, missing }
只看新变化

重新观察页面，返回变化对象的完整证据，列出未变化 ID。

{ status, sources, unchangedIds }

03 / INSTALL

运行包和 Skill，一次装好。

Node.js 22+ · Codex 桌面版 CUA · 你自己的 X 登录

npx @nextclaw/x-harness@latest setup --target codex

安装后，在 Agent 中使用 x-harness Skill。运行路径稳定，配置与台账属于你。

04 / START

从你的账号开始。

  1. 1

    安装，再初始化自己的工作区

    安装回执提供 CLI 路径。用 init --directory ./x-workspace --account 你的handle 建立配置、台账和证明目录。

  2. 2

    让 Skill 绑定已有浏览器

    Agent 读取宿主文档，使用你已登录的真实 tab，直接调用顶层任务 API。

  3. 3

    先读，再按授权执行

    初始化不规划任何写操作。发布与互动需要你的任务授权、审稿证据和台账计划。

05 / UPDATE

升级能力，保留自己的数据。

npx @nextclaw/x-harness@latest update --target codex

运行包与 Skill 同步更新。旧版本留备份，工作区不受替换影响。更新后重新绑定模块，再核验一次真实读取。

支持哪些宿主？

已验证 Codex 桌面版的 CUA 浏览器环境。--target claude 可安装 Claude Skill 文本，但该宿主仍须另外提供兼容的 CUA tab/app；安装 Skill 不会自动赋予浏览器控制能力。

开源许可是什么？

采用 AGPL-3.0-only，可用于个人与商业工作。再分发以及通过网络提供修改版本时，须履行许可规定的对应源码提供义务。查看完整 TypeScript 源码 ↗ · 阅读完整许可 ↗

写任务有哪些条件？

使用者自己授权、身份与目标证据齐全、原始台账有计划。当前写入窗口为上海时间 原创、关注 07:00–22:00，回复 07:00–24:00，以原项目合同的更严格限制为准；关注候选门要求已审阅的中文蓝标账号。结果未知时先核验，不能算成功或直接重发。
